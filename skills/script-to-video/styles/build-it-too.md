# You can build this too

## Stance
The viewer is going to clone this. Every beat answers "what would I change here."

## Leads with
The lowest bar you can honestly state. "If you can write a string, you can build this" works
because it is the actual requirement, not a slogan.

## Emphasize
- How small the integration really is. Name the line count when it is small.
- The seam a viewer would swap: the writer, the source feed, the prompt.
- The one constraint worth copying, and why it is what makes the thing portable.
- Tricks that save the viewer money or time, like caching raw audio per segment.

## Cut
Anything specific to the author's content that a viewer cannot reuse.

## Register
Second person. "You post plain text, you get audio bytes back."

## Length
Same as technical. Ends on a runnable command.

## Calibration line
> That is the hard part of this project and it is about fifteen lines.
